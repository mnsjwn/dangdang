# data/raw — 공공데이터 원본을 여기에 넣으세요

공공데이터포털에서 받은 CSV를 이 폴더에 그대로 넣고,
프로젝트 루트에서 아래를 실행하면 `data/foodDB.json`, `data/parks.json`이 다시 만들어집니다.

```bash
node scripts/build-data.mjs
```

## 넣어야 할 파일 2개

| 무엇 | 어디서 | 파일명 조건 |
|---|---|---|
| 식품 영양성분 (탄수화물) | [식품의약품안전처_식품영양성분DB 통합 자료집](https://www.data.go.kr/data/15047698/fileData.do) → **파일데이터** 탭에서 다운로드 | 파일명에 `영양성분` 포함 |
| 전국 도시공원 (위도·경도) | [전국도시공원정보표준데이터](https://www.data.go.kr/data/15012890/standard.do) → **파일데이터/다운로드** | 파일명에 `도시공원` 포함 |

받은 파일 이름을 굳이 바꿀 필요는 없습니다. 위 키워드만 들어 있으면 스크립트가 알아서 찾습니다.
(예: `식품의약품안전처_식품영양성분DB_20260101.csv`, `전국도시공원정보표준데이터.csv`)

## 참고

- 공공데이터포털 CSV는 대부분 **EUC-KR** 인코딩입니다. 스크립트가 자동으로 감지해서 처리하니
  그냥 받은 그대로 넣으면 됩니다.
- 엑셀(.xlsx)로 받았다면 엑셀에서 **다른 이름으로 저장 → CSV**로 바꿔서 넣어주세요.
- 공원 데이터는 전국 약 19,000건이지만, 스크립트가 **대전광역시 서구**만 걸러냅니다.
- 이 폴더의 원본 CSV는 앱에 번들되지 않습니다. 빌드 결과인 `data/*.json`만 앱에 포함됩니다.
